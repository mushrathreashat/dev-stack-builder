Dev Stack Builder

About

Dev Stack Builder is a React website where users can explore different technologies and build their own development stack.

Technologies

- React
- JavaScript
- Vite
- Tailwind CSS
- React Toastify
- JSON

Features

- Browse different technologies
- Add technologies to your stack
- Remove technologies from your stack
- Duplicate technology prevention
- Toast notifications
- Responsive design

React Questions

1. What is JSX?

JSX allows us to write HTML-like code inside JavaScript.

2. What is Props?

Props are used to pass data from a parent component to a child component.

3. What is State?

State stores data that can change inside a React component.

4. What is useState?

useState is a React Hook used to create and update state.

5. What is useEffect?

useEffect is used for side effects such as fetching data.

6. Why is key used in map()?

The key helps React identify each item in a list.

7. What is conditional rendering?

Conditional rendering means showing different UI based on a condition.
